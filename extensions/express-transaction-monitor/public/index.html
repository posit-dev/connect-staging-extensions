About this demo

This app is an example of running a Node.js app on Connect. It uses the Express framework to serve a shared fraud-review dashboard that updates live as new data arrives, with no page refresh.

The data is simulated. The server creates about one card transaction every second, so nothing you see is a real account or payment. A few simple rules flag suspicious charges, such as large amounts or charges from outside the US.

Flagged charges go to a shared review queue. Anyone viewing the app can acknowledge or escalate a charge, and everyone sees the result live over Server-Sent Events. Each action is labeled with the reviewer's Connect identity, which the server looks up from the signed-in viewer.

Review actions are recorded as "Anonymous analyst." Add the Connect Visitor API Key integration so each one shows the reviewer's name.
