About this demo

This page shows a live feed of card transactions, updating on its own without ever needing a refresh. About once a second, a new transaction comes in, and a few get flagged as possibly fraudulent, for example because the amount is unusually large or the charge came from an unexpected country.

Everything here is made up. The transactions, merchants, and card numbers are all simulated, so nothing you see is a real account or a real charge.

Flagged charges show up below under "Needs review." Anyone looking at this page can acknowledge one, meaning it looks fine, or escalate it, meaning it looks like real fraud. Either way, everyone else sees the decision right away, along with the name of whoever made it. Escalated charges then move down to the "Escalated" list, where they stay so the team can follow up on them later instead of them just disappearing.

A note for whoever manages this deployment: this app keeps everything (the feed, the review queue, the totals) in memory rather than a database, so it only works correctly as a single running copy. In this content's settings, on the "Runtime" tab, set Max processes to 1. It's also worth setting Min processes to 1, so the app doesn't stop and lose its data when nobody's used it for a while.
