Setup required

This app needs one more thing set up before it's ready to use: a way to know who's viewing it. Right now it can't tell who you are, so every review would be logged under "Anonymous analyst" instead of your name. Here's how to fix that:

  1. Open this content's settings by clicking the gear icon on its page in Connect.
  2. Go to the "Runtime" tab.
  3. Under "Integrations," click "Add Integration" and choose "Connect Visitor API Key" (or create one first, if none exist yet).

Once that's done, refresh this page and it'll switch over automatically. For more details, see the OAuth Integrations documentation.
