Real-Time Transaction Monitor

Setup required

This app couldn't resolve your Connect identity, so review actions would be attributed to "Anonymous analyst" instead of you. To fix it:

  1. Open this content's settings (the gear icon on its page in Connect).
  2. Go to the "Runtime" tab.
  3. Under "Integrations", select "Add Integration" and choose a "Connect Visitor API Key" integration (or create one if none exists yet).

For more information, see the OAuth Integrations documentation. Refresh this page once the integration is added.
