Configuration Required

The Connect Traces Viewer needs to be configured with environment variables to load trace data from a specific content item and job.

Required Environment Variables

To view traces, you must set the following environment variables that identify which content and job to load traces from:

INSTRUMENTED_CONTENT_GUID {{ 'Set' if has_content_guid else 'Missing' }}
INSTRUMENTED_JOB_KEY {{ 'Set' if has_job_key else 'Missing' }}

How to Configure

  1. Navigate to your content item in Posit Connect
  2. Go to the Vars tab
  3. Add the following environment variables:
    • INSTRUMENTED_CONTENT_GUID - The GUID of the content to trace
    • INSTRUMENTED_JOB_KEY - The job key to load traces from
  4. Save your changes and reload this page
