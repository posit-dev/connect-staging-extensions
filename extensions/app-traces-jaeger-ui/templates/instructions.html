How to Use

{% if is_running_in_connect %}

When running inside Connect, CONNECT_SERVER, CONNECT_API_KEY, and CONNECT_CONTENT_GUID are provided automatically by the Connect server.

The application is ready to use. You can select applications and jobs through the user interface to view their traces.

{% else %}
  1. Set the following environment variables in your shell or deployment configuration:
    • CONNECT_SERVER - URL of your Posit Connect server (e.g., https://connect.example.com)
    • CONNECT_API_KEY - Your Connect API key with access to the traces
  2. Restart the application to load the new environment variables
  3. Reload this page

Note: After configuring the connection, you can select applications and jobs through the user interface to view their traces.
